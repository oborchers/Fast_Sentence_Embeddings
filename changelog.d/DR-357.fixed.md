MemorySink, ShardSink and ScoreSink now reject boolean, floating-point, negative and oversized row arguments before allocation, reservation or commit state changes. Target sizes must fit the platform array index and byte-size limits, including sinks used by Heads. Targets spanning shards allocate their own buffer before reserving any shard rows, so a failed allocation cannot create a large chain of reservations. Python and NumPy integers remain supported.
