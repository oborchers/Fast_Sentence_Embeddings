Accept custom `os.PathLike[str]` objects consistently for local model files, model folders, caches, extra files, stores and sinks. Path objects are always local model references; only strings may identify a Hub repository. Byte paths remain invalid, and existing validation error classes are preserved.

Import `PathLike`, `ModelRef` and `WorkerCount` from `fse.typing` for common input annotations.

Accept one-dimensional NumPy text arrays as batches in encoding and prediction, including document IDs and position-based resume across stores of different lengths. Unicode, object and StringDType arrays use the existing dimension and row checks. Results retain the same bits as list batches. Score sink targets and store row locations expose their guaranteed array dtypes.
